# AI Query Assistant

An AI-powered chatbot built using Python, Flask, and Google's Gemini API.

## Features
- AI-powered question answering
- Interactive web interface
- Flask backend
- Gemini API integration

## Technologies Used
- Python
- Flask
- Google Gen AI SDK
- python-dotenv
- HTML, CSS, JavaScript

## Installation

Install the required dependencies:

```bash
pip install -r requirements.txt
```

Configure your Gemini API key in a local `.env` file. Never upload your API key to GitHub.

## Run the Application

```bash
python app.py
```
